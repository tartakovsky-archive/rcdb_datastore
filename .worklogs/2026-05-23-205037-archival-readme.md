## Key facts grounded in code
- Stack: FastAPI 0.63, SQLAlchemy 1.3, Alembic 1.5, Pydantic 1.8, TimescaleDB 2.1 (Postgres 12), Redis 6.2, Gunicorn + UvicornWorker, Sentry, AWS ECR/CloudWatch.

- Forex prices served from Redis, not Postgres.
